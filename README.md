il dettaglio. Le istruzioni di deploy complete arrivano in fondo, a fine

```bash
npm install
cp .env.example .env.local   # compila le variabili
npm run dev
```

Le pagine di prova (non stilizzate) sono sotto `/test/*` a partire da `/`.
